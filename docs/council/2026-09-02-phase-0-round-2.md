## Issues found and resolved

| Area | Round 2 finding | Resolution |
|---|---|---|
| Integrity | `asInvoker` can inherit high integrity from an elevated parent | Resident startup now rejects integrity above medium; elevated-client tests are required. |
| License/status | Public repository, “private spike,” and no license conflicted | Work remains documentation-only until the owner ratifies eight decisions; the repository is public-visible owner-only planning, not open source. |
| Hotkey/native fallback | Old text still permitted a Phase 1 bare-Windows-key experiment | Phase 1 has no hook; supported chord registration is nonfatal; `Ctrl+Esc` is the tested fallback. |
| Integration | Plain `--toggle` could not carry a RetroBar anchor | Added a strict versioned integrated form plus real-button and foreground-transfer evidence for G1b. |
| IPC | Names/`CurrentUserOnly` were overstated as authentication | Added explicit ACLs, peer token/session/integrity validation, exact bounds/timeouts, `FirstPipeInstance`, and an honest same-user threat limit. |
| Test arithmetic | “Balanced,” “100 runs,” ACKs, and duplicates were ambiguous | Defined an exact 1,000-case distribution, `50 × monitor_count` placement subset, state deadlines, ACK scope, process/HWND counts, and concurrency batches. |
| Performance | p95 criteria lacked a reproducible clock and sample protocol | Defined warm/cold-process states, samples, warm-ups, QPC boundaries, power state, and nearest-rank p95. |
| DPI | Target DPI before first show and “sharp” were underspecified | Added hidden two-stage first placement, target-scale checks, two-pixel bounds tolerance, named scale pairs, and separate text-size evidence. |
| Shell | A bounded STA queue was incorrectly suggestive of COM cancellation | UI waits are bounded; a wedged worker opens its circuit and degrades to cache/empty state without a cancellation claim. |
| Packaging | Upgrade/rollback/startup and alias failure were vague | Added exact N→N+1→N or N+2 sequence, one disposable StartupTask smoke test, fixed unpackaged launcher design, and a clear alias failure rule. |
| Evidence privacy | Required catalog/screenshots conflicted with redacted logs | Raw gate artifacts are private and separate from runtime diagnostics; only sanitized aggregates are public. |
| Visual states | Token roles and focus contrast diverged across documents | Created one canonical baseline with semantic tokens, state matrix, focus separation rule, layout DIPs, and contrast requirements. |
| Accessibility | Narrator and clipping criteria were subjective | Added exact UIA roles/patterns, a scripted Narrator journey, Accessibility Insights result, locales, display/text scales, contrast, motion, and touch checks. |
| Inert controls | Phase 1 footer could expose Power/Start controls that did nothing | Interactive footer controls are omitted; real power remains out of scope and native Start is tested through `Ctrl+Esc`. |
